# Pocket

一款极简风格的单机德州扑克游戏。界面以暖白、灰色和炭黑为主，没有传统赌场视觉元素，专注于牌局判断和节奏。

## 已实现

- 可自定义 2–6 人本地锦标赛，五个具有不同风格的 AI 对手；联机模式入口已预留但暂不开放
- 本地 AI 固定使用最高强度：420 次蒙特卡洛模拟，并结合行动范围、底池赔率、位置和 SPR 决策，不设置故意犯错档位
- 完整的翻牌前、翻牌、转牌、河牌和摊牌流程
- 盲注、庄位轮换、弃牌、过牌、跟注、加注、全下与边池结算
- 完整七张牌最佳五张牌型判断
- 可调行动节奏、自动下一手，以及发牌、行动、加注、弃牌、轮到玩家和胜负结算等轻量音效
- 键盘快捷键、移动端布局和降低动效支持
- 本机保存设置、胜率、最大底池与连胜记录
- 自动保存进行中的对局，可在准备大厅继续
- 每五手升级盲注，并显示下一盲注级别
- 实时显示每位玩家的本轮投入；玩家决策区只保留牌型、待跟注额和合法操作
- 当前行动者在顶部状态与对应座位同步高亮，并提供玩家回合提示音
- 桌面、矮屏笔记本、竖屏手机和横屏手机自适应布局
- 翻牌前使用独立起手牌范围与加注压力模型，避免多人桌连锁弃牌
- 大厅内点击“模型对手”会直接展开小型选择器，只显示已在项目本地配置的 OpenAI、DeepSeek、MiniMax、Kimi、GLM 或自定义兼容模型
- API Key、接口地址和模型名只从服务器侧 `.env.local` 读取，浏览器不会接收或保存密钥
- 选择模型后自动检测连接；选中的模型会用于全部对手，每位对手仍携带各自独立的打法技能
- 首页可切换“模型极致思考”：开启时分别请求 DeepSeek/GLM 的 `max`、OpenAI 推理模型的 `xhigh` 等供应商支持的最高档；关闭时使用标准推理深度。MiniMax M2.x 保持原生思考，M3 使用自适应思考
- DeepSeek 空 JSON 会自动改用普通结构化提示重试；MiniMax 使用官方推荐的 Anthropic Messages 兼容接口、输出截断重试，并自动适配中国区与国际区
- 五位对手分别拥有独立技能文件，完整描述身份、翻前、翻牌/转牌/河牌、尺度、适应、筹码深度、决策协议、输出要求和安全边界
- 模型失败、超时或返回非法动作时自动回退本地 AI
- 行动记录会按手牌和下注轮次审计每次模型请求，显示供应商、模型、对手、采用动作或本地 AI 回退结果，不记录 API 密钥
- 模型审计同时保存请求 ID、耗时、尝试次数、区域/格式恢复、Token 用量、结束原因、推理模式、可用时的内部推理字符数，以及经过隐藏思维内容过滤后的模型实际输出；输出包含动作摘要、牌力、范围、底池与尺度分析、替代动作、风险、实际采用的角色规则和置信度
- 每手结束可选“训练复盘”展示全部底牌，或“标准亮牌”只展示自己与摊牌玩家；复盘弹窗和牌型信息使用更大的可读排版
- 核心牌局规则按 2024 Poker TDA 标准校准，包括单挑盲注与行动顺序、每街烧牌、短码全下重开行动、边池、未跟注筹码退回和奇数筹码分配

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

本项目的启动脚本不继承终端里的 HTTP 代理变量，避免模型请求被发送到未启动的本机代理端口；不会修改系统或浏览器代理设置。

## 本地模型配置

复制 `.env.example` 为 `.env.local`（项目已附带一份空白 `.env.local`），只填写你准备使用的供应商，然后重新启动开发服务：

```bash
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_API_ENDPOINT=https://api.deepseek.com/chat/completions
```

OpenAI、MiniMax、Kimi 和 GLM 的完整变量名都在 `.env.example`。网页会自动识别已配置模型，未填写密钥的模型不可选择。若要接入其他 OpenAI 兼容服务，可在 `POCKET_CUSTOM_MODELS_JSON` 中追加任意数量的模型；示例同样写在 `.env.example` 中。

MiniMax 默认使用 Anthropic 兼容地址 `https://api.minimax.io/anthropic/v1/messages`。若密钥属于中国区，可把域名改为 `api.minimaxi.com`；程序也会在鉴权区域不匹配时自动尝试另一区域。本地开发时 `/api/ai-decision` 由 Node 服务直接转发，避免系统代理的 Fake-IP 被本地 Worker 误判为私网地址。

模型名没有写死在浏览器中。可以直接修改 `.env.local`，例如把 `MINIMAX_MODEL=MiniMax-M2.7` 改为 `MINIMAX_MODEL=MiniMax-M3`，保存后开发服务会重新加载；前提是该模型已在对应区域上线，并且当前 API Key 有访问权限。接口地址与 API Key 无需随模型名一起改动。

五个模型对手的策略分别位于 `app/opponent-skills/mira.ts`、`knox.ts`、`aria.ts`、`theo.ts` 和 `nova.ts`。每次请求只会附带当前行动对手的完整技能，服务端提示会要求模型逐项检查相关下注街、尺度、适应和边界，并在 `skillApplication` 中说明实际采用了哪条规则。服务端不再设置 120–260 字的简短输出要求，最高输出预算提升至 32,768 Token，并要求返回完整的结构化、可核验分析。模型可以在内部充分推理，但隐藏思维链不会写入页面或本地记录；审计只记录供应商返回的推理模式和长度证明。

## 牌局规则说明

本游戏采用无限注德州扑克锦标赛规则。按钮顺时针移动；单挑时按钮兼任小盲并在翻牌前先行动、翻牌后后行动；最低下注为大盲，最低加注等于本轮最近一次完整下注或加注；不足完整加注的全下不会为已经行动的玩家重新开放加注，但累计短码全下达到完整加注时会重新开放。全下后的主池和边池分别结算，未被跟注的筹码退回，平分底池的奇数筹码从按钮左侧首位符合资格的玩家开始分配。每条公共牌街会先烧一张牌。

正式非全下摊牌只要求仍持有有效手牌的玩家按顺序亮牌，弃牌者通常盖牌；本游戏在结算后额外显示全部底牌，仅用于单机复盘，不改变胜负与底池结算。
