# Pocket

一款极简风格的单机德州扑克游戏。界面以暖白、灰色和炭黑为主，没有传统赌场视觉元素，专注于牌局判断和节奏。

## 已实现

- 四人单机锦标赛，三个具有不同风格的 AI 对手
- 完整的翻牌前、翻牌、转牌、河牌和摊牌流程
- 盲注、庄位轮换、弃牌、过牌、跟注、加注、全下与边池结算
- 完整七张牌最佳五张牌型判断
- 三档 AI 难度、局面提示、自动下一手和轻量音效
- 键盘快捷键、移动端布局和降低动效支持
- 本机保存设置、胜率、最大底池与连胜记录

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

## 检查

```bash
npm run lint
npm run test
```
